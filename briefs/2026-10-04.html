🔐 Cyber Security

GitLab patches critical 9.9 AI Gateway flaw allowing command execution

CVE-2026-90970 let an authenticated Duo Agent Platform user escape the prompt-template sandbox via a crafted flow configuration and run arbitrary commands on self-hosted AI Gateway installs. Fixed in 19.2.4, 19.3.2 and 19.4.1; CISA lists exploitation as none so far.

Source: The Hacker News
📄 Exec summary
This is one of the first critical RCE flaws found in AI-specific infrastructure rather than traditional app code, and the root cause (unsanitised template input reaching a Jinja2-style engine) is a pattern likely to recur elsewhere. Action: if you run self-hosted GitLab AI Gateway, patch now; more broadly, treat any prompt/flow-configuration input to an LLM pipeline as untrusted and sandboxed, not just user chat input.
